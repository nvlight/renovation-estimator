# Документация Renovation Estimator

Документы описывают код **как он есть**, а не целевую архитектуру. Если поведение в коде расходится с этим текстом, приоритет у кода.

## Содержание

1. [Архитектура](architecture.md) — сервисы, слои Laravel/Quasar, аутентификация, политики, исключения.
2. [Предметная модель](domain-model.md) — сущности, поля, связи, каскады.
3. [HTTP API](api.md) — маршруты auth / v1 / v2, тела запросов, ответы, валидация.
4. [Фронтенд](frontend.md) — маршруты, Pinia, страницы, ключевые компоненты.
5. [Расчёты](calculations.md) — геометрия комнаты, натяжной потолок, гипсокартон, нормы материалов.
6. [Разработка](development.md) — тесты, сидеры, artisan-команды, известные ограничения.

## Карта пользовательского потока

```
Регистрация / логин
        │
        ▼
   Dashboard
        │
        ▼
   Проекты  ──►  Комнаты проекта  ──►  Спецификация комнаты
                                            │
                    ┌───────────────────────┼───────────────────────┐
                    ▼                       ▼                       ▼
              Геометрия стен         Калькуляторы работ      Материалы комнаты
              (SVG, замкнутость)     (ГКЛ / натяжной)        (справочник + смета)
                    │                       │                       │
                    └───────────────────────┴───────────────────────┘
                                            │
                                            ▼
                              Итого: материалы + работы (₽)
```

Справочник материалов живёт отдельно (`/materials`) и используется калькуляторами по `id`.

Схема выше показывает предметный поток. В текущем layout нет меню приложения: с Dashboard к `/projects` и `/materials` нужно перейти по URL напрямую; дальнейшие переходы проекты → комнаты → спецификация реализованы кнопками и breadcrumbs.
